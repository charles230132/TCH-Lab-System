# 陽明院區檢驗科採檢查詢

以陽明院區採檢手冊 TCHYM-QP-7.2-2-(1)（審查紀錄115.05.19）PDF提供ICU採檢快查、健保碼查詢及全文、參考值原頁查詢。

## 資料與顯示原則

- 主資料是 `data/manual115.pdf`（陽明現行手冊，來源：檢驗科共用文件夾115年QP），共89頁。來源檔名及SHA256記錄於 `data/source_manifest.json`。
- 品牌為「臺北市立聯合醫院陽明院區檢驗科」，手冊頁首亦為陽明院區。2026-11-23由中興院區手冊（TCH-QP-7.2-1-(1) 1150420）改為陽明手冊。
- 六項ICU快查論點、27項採檢論點及10項健保碼對照的追溯表在 `data/verified_claims.json`，每項標示來源頁碼與核對狀態。陽明手冊版論點已通過程式逐字核對與Claude判讀；Codex盲審未做（四爺2026-11-23裁示直接上線），review_status欄位如實標示。
- 藍頭凝血管：手冊p.7列1.8cc、3.8%，p.12列至刻度2.7ml，與現用管不同；網站依檢驗科確認的現用管（2 mL、3.2%，採至箭頭）提示，並列出手冊兩處寫法。
- 健保碼查詢保留開頭的0，接受全形數字，並依完整代碼比對，不把08014擴充成08011。常用項目提供10列已核對的名稱／代碼／原頁對照，完整手冊其他項目可依健保碼搜尋原表；同碼的動靜脈血氣、不同CBC組合均保留原有區別。
- 健保碼搜尋保留已核對的跨頁續表，續頁明確標示「續表」；不宣稱代碼直接出現在續表頁。網站頁首與頁尾顯示版本 `115-YM-20261123` 及最新更新日期，可供公開部署後辨識與評鑑查核。頁面下方設有「錯誤回報」區：目前僅提供電話回報；Google表單網址設定於 app.py 的 FEEDBACK_FORM_URL 後才顯示表單按鈕，且只預填頁碼與網站版本，不帶搜尋文字。
- 成人血液培養量另列CDC外部指引補充，保留「範例目標」與「以現用血瓶規格確認」的限制。不能把手冊第20頁的6–20ml（每瓶）直接當作成人每瓶通則。
- 參考值、年齡、性別、院區與量測不確定度以原始表格頁面呈現，不再用固定位置猜欄位，也不按項目名稱刪掉不同族群的列。
- 其他檢驗項目皆可全文檢索並開啟原頁，包含完整表格及臨床意義。原頁屬直接來源檢視，不宣稱所有來源段落均已逐條完成語意核對。
- 不以Git checkout或伺服器檔案時間充當內容修訂日期。

## 執行

```powershell
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

## 更新資料

明確取得並核對新版PDF後，才重新產生來源索引：

```powershell
python build_source_index.py '採檢手冊.pdf'
python -m pytest -q
```

更新快查規範時須同步完成使用者要求的三重核對及追溯表，不能只換PDF便沿用不相符的快查內容。

GitHub Actions已改成唯讀驗證，移除每10天抓取網站並覆寫資料庫的排程。舊的SQLite資料與更新腳本不再供新程式使用；歷史版本仍可由Git查回。
